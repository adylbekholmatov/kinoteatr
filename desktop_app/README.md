# AKI Cinema Admin — Приложение кассира

## Требования
- .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
- Windows 10/11
- Django сервер должен быть запущен

## Запуск

1. Откройте PowerShell в папке desktop_app\AKICinemaAdmin
2. Выполните:

```powershell
dotnet run
```

Или откройте AKICinemaAdmin.csproj в Visual Studio 2022 и нажмите F5.

## Функции
- Вход с логином/паролем администратора Django
- Расписание сеансов на любую дату
- Интерактивная схема зала с выбором мест
- Оформление билета с номером телефона клиента
- Печать билета
- Поиск бронирования по коду
